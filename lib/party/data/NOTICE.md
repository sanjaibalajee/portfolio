# Word-bank license

`words.json` adapts English words and hints from [Fvitu/Impostor-Game](https://github.com/Fvitu/Impostor-Game/blob/b1913f31bfdb88c435f233e07025f462c187d5cd/lib/game-data.ts), pinned to `b1913f31bfdb88c435f233e07025f462c187d5cd`. Duplicate English labels are removed; topics, difficulty, concept IDs and audience ratings are our additions. No upstream transport or game code is used. Other packs and game code are authored here.
